# Dashboard - Unidad II AE1

El dashboard permite visualizar el diagnostico del dataset original sin modificarlo.

## Ejecutar

Desde la raiz del proyecto:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run dashboard/app.py
```

Se abrira normalmente en `http://localhost:8501`.
